# Katalog perintah HdyBot → Hermes

Dibuat otomatis dari `parser.ts`, `menu.ts` dan `FEATURE_INVENTORY.md`. Kolom *Strategi*: **skrip** = sudah ada skrip siap pakai; **hermes-native** = Hermes mengerjakan sendiri (tool bawaan/aturan di SKILL); **perlu-port** = butuh kode/kredensial tambahan; **diganti-hermes** = fungsi sudah dicakup Hermes sendiri.
